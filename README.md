# GenAI Prompt Engine using LangChain

## 📌 Objective
Build reusable and dynamic prompt systems using LangChain PromptTemplate.

## 🚀 Features
- Dynamic PromptTemplate usage
- Multi-input prompt system
- Prompt variations (teaching, interview, storytelling)
- ChatPromptTemplate with roles
- Input validation layer
- Prompt generator function
- Template reusability testing

## 🛠️ Tech Stack
- Python
- LangChain
- Jupyter Notebook / Google Colab
